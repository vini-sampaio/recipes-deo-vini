# Vini & Deo Recipes

Our personal recipe book, built on the Vini's Kitchen design system.

## Run it
Open `index.html` in a browser. Or, from this folder: `npx serve .` and open the address it prints.

## Add a recipe
Add an entry to `src/recipes.js`. See `CLAUDE.md` for the format.

## Working with Claude Code
Open this folder in Claude Code. `CLAUDE.md` explains the structure, the recipe format and the design rules, so you can ask things like "add this recipe as dinner: <link>".
